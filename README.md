# Telegram-бот: каталог и заказы для малого бизнеса

Демо-бот для кофейни: клиент листает каталог, собирает корзину и оставляет заказ прямо в Telegram, а владелец сразу получает уведомление. Легко переделывается под любой малый бизнес: кафе, пекарню, цветочный магазин, косметику, магазин одежды, услуги.

## Что умеет

- 📋 Каталог по категориям: карточка товара с описанием и ценой
- 🛒 Корзина: добавить, увеличить или уменьшить количество, очистить
- ✅ Оформление заказа: имя, телефон (кнопкой или текстом), комментарий
- 🔔 Владелец мгновенно получает заказ: состав, сумма, кликабельное имя клиента
- 💬 «Задать вопрос»: вопрос клиента приходит владельцу
- 🛠 Команда `/admin` для владельца: последние заказы
- ℹ️ Раздел «О нас и контакты»
- Заказы сохраняются в файл `orders.json`

## Как запустить

1. Создай бота в Telegram через `@BotFather` (команда `/newbot`) и скопируй токен.
2. Скопируй `config.example.py` в `config.py` и вставь токен в `TOKEN`.
3. Установи библиотеку: `pip3 install -r requirements.txt`
4. Запусти: `python3 bot.py`
5. Напиши боту `/id`, он пришлёт твой Telegram ID. Впиши его в `config.py` в `OWNER_ID` и перезапусти бота, чтобы получать заказы.

## Как переделать под другого заказчика

Все настройки лежат в начале файла `bot.py`, раздел «Настройки»: название, адрес, телефон, часы работы, валюта и сам каталог (категории, товары, цены, описания). Менять код логики не нужно.

## Технологии

Python 3, библиотека pyTelegramBotAPI, хранение заказов в JSON-файле.
